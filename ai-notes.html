杂乱笔记

手打版

我看完飞天闪客的“一小时从函数到 Transformer”之后才搞明白神经网络......就像是泰勒展开一样，追求“拟合”，或者说“函数逼近”，用矩阵计算去拟合出一个对于每一种输入内容都有对应的正确输出的“函数”，这让我想起了刚上高中将函数f（x）概念的时候，说f（x）是一个“工厂”，只是神经网络这个“工厂”是黑箱。

把神经网络看成一个函数，网络架构（输入输出层，隐藏层的神经元数量，层的个数等等）决定这个函数由什么结构组成，网络参数决定这个函数具体是什么样子

强化学习是一种学习（训练）方法，标准强化学习是人工设计特征，训练价值函数。设计的特征可以描述整个状态

深度强化学习是用神经网络去拟合价值函数或策略网络，可以省去特征工程的过程，直接端到端

不需要把所有概念都彻底搞懂，比如encoder（编码器），作用是把原始输入数据转换成更有用的特征表示（Feature Representation），供后续网络使用。可以先把它理解成：Encoder负责理解输入信息，提取其中重要的特征

不需要去看代码中encoder是怎么实现的，现在你已经可以理解encoder的作用了，就像飞天闪客那个视频里一样，不求甚解，但是看到后面你发现原来自己知道的内容已经足以理解后面的一条链路

RL 算法根据奖励和策略梯度，计算如何调整网络参数

正向传播 根据输入计算网络输出
损失函数 衡量网络输出与学习目标之间的差异
反向传播 计算损失对网络参数的梯度
梯度下降 根据梯度调整网络参数

反向传播负责计算，梯度下降负责更新。

DreamWaQ（ICRA 2023，KAIST）

一句话：只喂 Unitree A1 本体感知（IMU + 12 个关节角度/角速度）最近 5 帧，直接输出 12 个关节目标角，50 Hz 闭环；无相机、无激光雷达，零样本 sim-to-real。官方代码未开源。

要解决的问题

  • 感知式（相机/LiDAR）在坏天气、逆光、雪地（看着硬、实际软）、高草（看着过不去、实际能踩）上不可靠；
  • 纯本体感觉的 teacher-student（RMA 类）：学生能力被老师封顶、两阶段数据效率低、学生探索不到老师踩过的失败状态；
  • 表示学习瓶颈（鸡生蛋）：策略要懂地形才能走好，要懂地形得先走起来采集足底反馈。

押注：非对称 actor-critic，单阶段训练——critic 在训练期看特权 s_t=[o_t, v_t, d_t, h_t]（真值速度、随机扰动力、高程图），policy 只看历史 o^H_t；PPO 的价值信号逼 policy 从本体历史里"想象"地形。另加 CENet 联合估计速度 v̂ 与地形 latent z。

架构

  • CENet：o^H_t（5 帧 × 45 维 = 225）→ 共享编码器 128→64→19 = 3(速度) + 16(latent)；速度头 MSE 监督 v̂；β-VAE 头 z → 解码器 64×128 → 重建 o_{t+1}
  • Actor：o_t(45) + v̂(3) + ẑ(16) = 64 维 → 512→256→128→12
  • Critic：s_t → V(s)，512→256→128→1，只活在训练期

损失（式 1–4）

L_CE  = L_est + L_VAE
L_est = MSE(v̂_t, v_t)                                     # 速度回归（仿真真值）
L_VAE = MSE(õ_{t+1}, o_{t+1}) + β·KL(q(z|o^H_t) ‖ N(0,I))  # 重建下一帧 + KL

AdaBoot（式 5）：p_boot = 1 − tanh(CV(R))，R 是 m 个环境回合奖励——奖励分散（还没学会）时少自助采样，奖励一致时多；用来平衡"估计不准时靠估计值"与"估计器噪声损伤策略"。

数据与接口

  • 每帧 45 维：ω(3) + g(3) + c(3) + θ(12) + θ̇(12) + a_{t-1}(12)；H=5
  • 动作 12 维关节角偏移：θ_des = θ_stand + a_t；policy 50 Hz，PD 200 Hz（A1：Kp=28, Kd=0.7）
  • 仿真：Isaac Gym 4096 环境、1000 迭代、RTX 3060Ti 约 1 小时；域随机化 7 项（质量、质心、负载、Kp/Kd、电机强度、摩擦、系统延迟）
  • 小矛盾：图 2 解码器标注 48，正文公式算 45（差 3 维，论文没解释；社区复现理解成"观测里塞了真机速度"后改回 45）

结果：学习曲线接近 oracle（带高程图的特权策略）；真机 A1 单次连走校园场地 430 m、山路 465 m；抗扰（最大推速 1.12 m/s、存活率 95.2%）优于 Baseline / RMA / EstimatorNet。

现状：官方代码未开源；社区复现多（如 dreamwaq-isaaclab、go2_dreamwaq）。

HIM / HIMLoco（CoRL 2024，上海 AI Lab）

一句话：与 DreamWaQ 同族——历史 5 帧、显式估速度、隐式表征 16 维、与 policy 交替训练；核心差别是隐式表征用对比学习（SwAV 风格）而不是重建。官方代码开源（HIMLoco），A1/Go1/Aliengo 上 50 Hz 部署（PD 500 Hz）。

核心思路（IMC 类比）：不直接估扰动（地形/摩擦/高程），而是用"内部模型"估机器人对扰动的响应；hybrid internal embedding = 显式速度 v̂（MSE 真值）+ 隐式稳定性表征 l̂（16 维）。

架构

  • 编码器：o^a_{t-H:t}（历史）→ 128→64→19 = 16 + 3
  • target 编码器：o_{t+1} → 128→64→16
  • Actor：o^a_t(45) + v̂(3) + l̂(16) = 64 维 → 512→256→128→12
  • Critic：特权输入（含外力、高度扫描 187）

关键机制：对比学习（HIO 的一部分）

  • 历史编码与下一帧编码 L2 归一化到单位球 → 与 K 个可学习原型做 softmax 得分配 p_src / p_tgt；Sinkhorn-Knopp 在 batch 上均衡分配得目标 q（防塌缩）
  • 损失（式 2）：
J = −(1/2H) Σ_t [ q_src·log p_tgt + q_tgt·log p_src ]
  • 正对 = 同一轨迹相邻步；负对 = 不同环境的样本（4096 个环境白捡的负样本）
  • 数字：原型 K=32（代码默认；附录写 16）、温度 τ=3、Sinkhorn ε=0.05×3 次；历史输入 270=45×6（论文写 H=5）

为什么不用重建：下一帧 45 维都是噪声敏感的关节量，逐维重建被噪声和 sim2real 分布差淹没；对比只要"响应类别"判对——更稳，还能用 batch 级（跨环境）信息。论文图 4 的 t-SNE：HIM 的环境簇比回归版（DreamWaQ 的 z）分得开。

训练：HIM 与 PPO 交替——先 estimator.update（MSE 速度 + 对比损失，独立优化器），再冻结 / 用 detached 输出训练 actor + critic；Isaac Gym 4096 环境、RTX 4090 约 1 小时（1000 rollouts）。

术语速查

术语 一句话
PPO 强化学习算法（不是网络架构），用 clip 目标 + 价值函数更新策略
GAE 优势函数的多步平滑估计（λ）
advantage Â "这一步比预期好多少"，驱动 PPO 更新
β-VAE 变分自编码器，β 加权 KL 惩罚，逼 latent 近似标准正态且压缩
SwAV 一种自监督对比学习：样本映射到原型、Sinkhorn 均衡分配，不需显式负样本
Sinkhorn-Knopp 把分配矩阵迭代归一化到行列均衡的算法，防塌缩
IMC 内部模型控制：用模型模拟系统响应来估计扰动
teacher-student 老师看特权信息学策略，学生只靠本体历史模仿老师

我的问题与回答（对话记录）

  • Q：CENet 靠历史信息让机器人猜自己的速度和周围地形，那 RMA、HIM 这些怎么解决？
    A：四条主线——RMA / AdaptationNet（teacher-student 蒸馏隐式环境因子）；EstimatorNet（并发估计显式状态）；HIM（IMC 思想 + 对比学习隐式响应）；DreamWaQ（非对称 AC + β-VAE 重建下一帧）。
  • Q：为什么 DreamWaQ 重建的是"下一帧"？历史不是收集过往信息吗？
    A：历史是输入，下一帧（o_{t+1}）是监督目标——仿真里现成的真值（teacher forcing）。重建输入里已有的帧是恒等映射、学不到东西；下一帧是"动作 × 地形"的响应，想预测准就只能把摩擦 / 坡度等隐变量压进 z。部署时只做一次前向，不需要"未来"。
  • Q：critic 只出价值，"出"的是什么？
    A：出标量 V(s_t) = 从 s_t 出发的期望折扣回报。训练时用 TD 目标回归它，同时用 Â = r + γV(s_{t+1}) − V(s_t)（GAE 版）得到 advantage，PPO 的 −min(ρ·Â, clip(ρ)·Â) 决定这一步动作概率抬还是压。critic 只活在训练期，因为它吃特权 s_t。
  • Q：监督学习不是要带答案吗？
    A：要。仿真 rollout 里 o_{t+1}、v_t 都是现成真值，所以 CENet 是"自监督重建 + 有监督速度回归"；policy 那支才是强化学习（PPO）。三条损失流各学各的，共用同一批仿真数据。
  • Q：两篇论文的网络架构都是 PPO 吗？
    A：PPO 是算法不是架构。架构是普通 MLP：actor 512→256→128→12、critic 512→256→128→1、CENet 编码器 128→64→19 / 解码器 64→128→48。（emmm）
  • Q：V_t 是 MDP 里的状态价值函数吗？
    A：是 state-value，V(s_t) = E[Σ γ^k r_{t+k}]。环境建模成 POMDP（策略只看部分观测），但价值函数定义在完整状态上——所以 critic 训练时可以看特权信息而不矛盾。
  • Q：原型簇是什么？
    A：HIM 隐空间里 K 个可学习"响应类别"中心（簇心）。样本编码到簇的 softmax 分配 p；Sinkhorn 把 batch 分配搬匀成 q；损失让"历史编码"和"下一帧编码"互相预测对方的目标簇。原型自己学出来，大致对应"平地 / 打滑 / 上台阶…"这类响应类别。
  • Q：HIM 是靠"看错题"吗？
    A：基本对，更准是"看同类 + 看异类"：同一轨迹的对比对要进同一簇，不同环境的样本互推。目的是让 l̂ 携带"这段响应属于哪种环境"的信息（policy 才能凭本体感觉识别地形）；作用是用比逐维重建更稳的信号替代重建（重建被 45 维噪声和 sim2real 差距淹没；4096 个环境提供天然负样本，重建法用不上）。论文图 4 的 t-SNE 是证据。
